# 宇宙之心软件技术说明手册

## 1. 产品定位：填补思维工具鸿沟

### 1.1 问题陈述

军事指挥官、顶尖学者、商业精英长期使用高阶思维工具：
- **OODA 循环**（Observe–Orient–Decide–Act）用于快速决策与对抗。
- **情报结构化分析**（ACH、STAR、关键假设检查）用于处理不确定性。
- **证据链与因果链**用于法庭、科研与战略推演。
- **项目管理/作战规划**（WBS、PERT、甘特/执行图）用于将认知转化为行动。

这些工具长期被锁在军校、智库、咨询公司与顶级实验室内部，普通学习者、独立研究者、中小型创业者难以触达，更难以将「思考」与「执行」连为一体。

**宇宙之心的目标**：把上述高阶思维方法平民化、软件化、AI 增强化，让普通人也能在单一工作流中完成「理解 → 推理 → 规划 → 执行 → 复盘」。

### 1.2 核心命题

> 知识图谱是记忆，推理是理解，执行是验证，反事实是原创。

宇宙之心不是笔记工具、不是静态思维导图、不是单一 Chat 应用，而是一个**因果推理 + 项目执行的认知操作系统**。

## 2. 系统架构（v1.8.3）

### 2.1 双视图核心

| 视图 | 数据格式 | 职责 | 当前实现 |
|---|---|---|---|
| **3D 知识图谱** | JSON（节点、关系、属性、证据） | 理解、拆解想法、描述节点关系 | `Graph3D`（`react-force-graph-3d`） |
| **2D 执行图** | Markdown 规划文档 + 任务节点 | 项目管理、规划、执行、跟踪 | `ExecutionGraph2D`（`@xyflow/react`） |

### 2.2 三层推理模型（Judea Pearl 因果阶梯）

```
L3 反事实推理  ← 边界条件、漏洞、原创
      ↑
L2 干预推理    ← 控制变量、最小实验
      ↑
L1 关联观察    ← 节点、关系、证据库
```

- **L1**：3D 知识图谱、证据库、内容区块（热力图/星云）。
- **L2**：干预假设卡片、最小实验设计、条件-依赖图。
- **L3**：反事实场景、边界条件清单、冲突检测、全局审查。

### 2.3 MAPS 多 Agent 架构

参考 `docs/AGENT_ARCHITECTURE.md`，系统由四类 Agent 协作：
- **Memory Agent**：负责知识的表征、聚类、持久化。
- **Analysis Agent**：负责证据审查、冲突检测、因果推断。
- **Planning Agent**：负责将推理结果转化为任务与执行计划。
- **Supervision Agent**：负责注意力监督、训练、复盘提醒。

### 2.4 数据持久化

- **本地优先**：IndexedDB + localStorage，Project 对象统一保存：
  - `nodes`、`links`（3D 知识图谱）
  - `executionTasks`（2D 执行图，含 `position`、`dependsOn`、`nodeId`、`clusterId`）
  - `contentClusters`、`nebulaMode`（热力图/星云记忆）
  - `globalReview`（全局审查结果）
  - `reasoningThreads`、`evidenceItems`、`changeLog`
- **导入/导出**：JSON 项目文件 + Markdown 规划文档。

### 2.5 当前关键技术栈

- **框架**：Next.js 14 + React + TypeScript
- **3D 图**：`react-force-graph-3d` + Three.js
- **2D 执行图**：`@xyflow/react`
- **状态管理**：Zustand（持久化到 localStorage）
- **数据库**：Dexie.js（IndexedDB）
- **AI 后端**：Next.js API Routes + OpenAI/兼容 LLM
- **样式**：Tailwind CSS

## 3. 当前功能模块

### 3.1 3D 知识图谱

- 节点/关系创建、编辑、拖拽。
- 层级钻取（点击节点进入子视图，面包屑返回）。
- 多选、Shift+单击节点连线、右键空白处添加节点。
- 内容区块热力图/星云视图。
- 节点便签（StickyNote）详情面板。

### 3.2 证据与推理

- 证据库：来源、可信度、摘要、关联节点。
- 逻辑推理线程：L1/L2/L3 三层画布。
- 冲突检测：本地启发式 + AI 深度检测，输出行动建议。
- 全局审查：多维度评分与问题清单，结果持久化。

### 3.3 2D 执行图

- 任务节点可拖拽、可编辑、可连接依赖。
- Markdown 规划文档编辑器，与 2D 节点双向同步。
- AI 规划：
  - **AI 图谱规划**：读取 3D 项目 JSON，输出 Markdown 执行计划。
  - **AI 目标规划**：基于用户目标生成 Markdown 执行计划。
- 导出/导入 Markdown 执行顺序。
- 读取其他项目任务合并到当前执行图。

### 3.4 项目与协作入口

- 项目新建/保存/加载/导入/导出。
- 顶部工具栏快速添加节点、切换 3D/2D/推理视图。
- 变更日志、学术搜索、聊天面板（源码保留，入口调整中）。

## 4. 未来 roadmap：OODA、证据链、结构化分析

### 4.1 OODA 循环工作台

在 2D 执行图或新增「OODA」视图中实现：
- **Observe（观察）**：从 3D 图谱、证据库、外部信源拉取关键信息。
- **Orient（判断）**：结合全局审查、冲突检测、内容区块生成态势判断。
- **Decide（决策）**：基于假设-干预-反事实推理，输出可选决策路径。
- **Act（行动）**：直接生成执行图任务并跟踪反馈。
- 支持循环迭代：行动结果回流为新的观察输入。

### 4.2 证据链（Chain of Evidence）

- 每个图谱节点可挂载证据项，形成「主张 → 证据 → 来源」链。
- 可视化证据链：从原始资料到最终结论的完整链路。
- 证据权重、可信度衰减、来源独立性检查。
- 导出法庭/论文/报告级证据链报告。

### 4.3 结构化分析技术（Structured Analytic Techniques）

逐步集成情报分析标准方法：
- **ACH（Analysis of Competing Hypotheses）**：竞争假设分析。
- **STAR（Structured Analytic Techniques Reference）**：关键假设检查、偏差检查。
- **因果图/贝叶斯网络**：从不确定性到概率化推理。
- **场景分析**：多未来路径规划与压力测试。

### 4.4 能力包操作系统（v3 愿景）

参考 `docs/v3_PROCESS_DESIGN.md`：任何目标可拆分为「知识 / 数据 / 设备 / 组织」四包，每包经历「问题 → 原理 → 实验 → 工程 → 场景 → 监控 → 复盘」七步闭环，沉淀为可复用模板。

## 5. 竞品分析

### 5.1 上位 AI4S 战略的学术工具版本

**代表方向**：Elicit、Consensus、ResearchGPT、SciSpace、Perplexity Pro、机构自研 AI4S 平台。

| 维度 | 上位 AI4S 学术工具 | 宇宙之心 |
|---|---|---|
| **核心目标** | 加速科研发现、文献综述、假设生成 | 把学术推理方法平民化，连接思考与执行 |
| **数据输入** | 论文、实验数据、文献库 | 任意文本、用户思考、证据、项目记忆 |
| **输出形态** | 论文摘要、证据表格、研究思路 | 3D 知识图谱 + 2D 执行图 + Markdown 规划文档 |
| **推理深度** | 强在文献检索与统计摘要 | 强在因果推理（L1→L2→L3）与项目落地 |
| **执行闭环** | 弱，主要停在认知层 | 强，可生成任务、跟踪执行、复盘沉淀 |
| **用户群体** | 科研人员、研究生、药企/实验室 | 独立研究者、创业者、分析师、终身学习者 |

**差异化**：AI4S 工具回答「研究什么、证据是什么」；宇宙之心回答「如何思考、如何验证、如何执行」。

### 5.2 印度商业的专精版本

**代表方向**：印度市场近年涌现大量「AI Business Coach」「Startup Planning AI」「Strategy OS」类产品，如部分基于 Notion/ChatGPT 封装的项目管理 + 商业画布工具，以及专注印度 SME/创业生态的本土 SaaS。

| 维度 | 印度商业专精版本 | 宇宙之心 |
|---|---|---|
| **核心目标** | 商业计划生成、融资准备、市场策略 | 通用高阶思维方法，军事/学术/商业皆可复用 |
| **方法模型** | 商业画布、SWOT、TAM/SAM/SOM、OKR | Pearl 因果阶梯、OODA、证据链、结构化分析 |
| **可视化** | 多为表格、画布、甘特图 | 3D 知识图谱 + 2D 执行图 + 推理画布 |
| **深度** | 模板驱动、偏执行层 | 认知增强、推理-执行闭环 |
| **本地化** | 强（印度法规、税务、本地案例） | 通用框架，用户自行填充领域知识 |

**差异化**：印度商业工具多为「模板 + 文本生成」；宇宙之心是「认知操作系统 + 推理执行引擎」。

### 5.3 其他常见工具对照

| 工具类型 | 代表 | 不足 | 宇宙之心补足 |
|---|---|---|---|
| 思维导图 | XMind、MindMeister | 静态、无推理层 | 3D 动态图谱 + 证据/冲突/反事实 |
| 笔记软件 | Notion、Obsidian | 缺乏结构化推理 | 内置 L1/L2/L3 推理画布 |
| 项目管理 | Jira、Trello、Asana | 只管理执行，不理解知识 | 2D 执行图直接读取 3D 知识图谱 |
| AI Chat | ChatGPT、Claude | 对话即走，无记忆闭环 | 项目级记忆、可审查的推理链 |

## 6. 典型使用流程

```
1. 在 3D 知识图谱中拆解问题、建立节点与关系
2. 添加证据、运行冲突检测、完成全局审查
3. 使用逻辑推理线程完成 L1→L2→L3 检验
4. 切换到 2D 执行图，点击「AI 图谱规划」
5. AI 读取 3D 项目 JSON，输出 Markdown 执行计划
6. 人工修改 Markdown，同步为 2D 任务节点
7. 拖拽调整顺序/依赖，执行任务并标记状态
8. 复盘结果，把验证后的知识沉淀回 3D 图谱
```

## 7. 扩展与集成接口

- **LLM Provider**：OpenAI 兼容 API，可配置 baseURL、model、apiKey。
- **导入格式**：Markdown（执行计划）、JSON（项目文件）。
- **导出格式**：Markdown、JSON、变更日志。
- **未来接口**：证据链报告、OODA 工作台、结构化分析模板、多人协作 WebSocket。

---

## 8. 安全与隐私

- 本地优先：数据默认保存在用户设备 IndexedDB。
- AI 调用仅通过用户配置的 LLM API Key 发起。
- 敏感项目可完全离线运行（不配置 LLM 时仍支持手动编辑与可视化）。

## 9. 总结

宇宙之心 v1.8.3 已经实现：
- 3D 知识图谱（理解层）
- 证据/推理/冲突/审查（推理层）
- 2D 执行图 + Markdown 规划文档（执行层）
- 项目级统一持久化

下一步将围绕 **OODA 循环、证据链、结构化分析** 三条主线，把军事、学术、商业精英的思维方法进一步平民化、软件化，最终形成个人/小型团队的认知操作系统。
