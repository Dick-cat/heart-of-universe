# 宇宙之心 v1.3 开发日志

> 目标：在 v1.2 的本地学习工具基础上，引入**单人版项目驾驶舱**概念，并通过一次 UI 架构升级，把所有 AI/学术/视觉/证据工具统一归位，把右栏信息从固定面板解放为可自由操作的便签。

---

## 1. 版本定位

v1.3 是 v1.x 到 v2.0/v3.0 之间的**过渡版本**：

- 保留 v1.2 的全部本地优先能力（注意力、视觉监督、学术搜索、证据审查）。
- 新增**项目驾驶舱雏形**：底部控制台承载时序编辑、逻辑树输入、Agent 协作。
- 进行**UI 架构重构**：工具面板集中到右上角，节点详情变成可缩放/移动/关闭的便签。
- 继续不做后端、账号、支付、多人协作。

---

## 2. 核心改动

### 2.1 UI 架构升级

| 原位置 | 新位置 | 说明 |
|---|---|---|
| 左下角注意力仪表盘 | 认知训练面板内部 | 已完成于 v1.2 第二轮迭代 |
| 右下角 AI/Agent/更新日志 | **右上角** | 与学术/视觉/证据工具统一 |
| 右侧固定节点详情栏 | **浮动便签** | 可缩放、移动、多开、关闭 |
| 无 | **底部控制台** | 新增项目驾驶舱入口 |

### 2.2 右上角工具矩阵

```text
┌─────────────────────────────────────────┐
│  [AI] [学术工具] [视觉监督] [证据仪表]   │
└─────────────────────────────────────────┘
```

- **AI**：ChatPanel（原右下角）
- **学术工具**：学术搜索 + 学术审查（合并为单一入口）
- **视觉监督**：VisualSupervisionPanel
- **证据仪表**：EvidenceReviewDashboard

### 2.3 底部控制台（Project Cockpit Console）

控制台位于窗口底部，左侧与左栏对齐，右侧延伸至右边缘。

| 组件 | 功能 |
|---|---|
| **时序编辑器** | 按时间线组织项目节点/事件/实验，支持拖拽排序 |
| **逻辑树输入** | 快速输入父子节点、依赖关系，生成逻辑树 |
| **Agent 架构** | 多 Agent 协作控制台：项目教练、领域专家、文献研究员、审稿人 |

控制台可拖动上边缘调整高度。

### 2.4 节点便签（Node Sticky Notes）

- 点击节点不再打开固定右栏，而是生成一个浮动便签。
- 可同时打开多个便签，每个显示不同节点。
- 便签支持：
  - 拖动标题栏移动
  - 拖动右下角缩放
  - 关闭按钮
  - 最小化到便签栏

## 3. 技术方案

### 3.1 布局调整

- 主布局改为 flex column：
  - 顶部：工具栏
  - 中部：左栏 + 主画布 + （便签浮动层）
  - 底部：控制台（可折叠/调整高度）
- 使用 CSS Grid / Flex 实现响应式拖拽分隔。

### 3.2 状态管理

- 新增 `useStickyNotes` store slice：管理打开的节点便签列表。
- 控制台高度、左栏宽度持久化到 localStorage。

### 3.3 Agent 架构

v1.3 中的 Agent 从"单次调用模拟多角色"升级为"多轮独立调用"：

- 每个 Agent 有独立的系统提示词与工具集。
- Agent 之间通过共享的项目上下文（目标、逻辑树、证据库）协作。
- 用户可以手动选择触发哪个 Agent，或让项目教练自动调度。

## 7. 第三轮迭代：学术搜索优化与多 Agent 架构

### 7.1 学术工具优化

- 学术工具按钮改为纯图标（📚），与其他工具按钮尺寸一致。
- 打开的面板层级提升至 `z-50`，避免被其他工具按钮遮挡。
- 右上角按钮统一为 `h-10 w-10` 正方形图标按钮。
- 学术搜索结果新增匹配标签：
  - 标题匹配 / 摘要匹配 / 作者匹配
  - 命中关键词列表
  - 标题与摘要中的命中词高亮

### 7.2 多 Agent 架构（MAPS）

- 设计文档：`docs/AGENT_ARCHITECTURE.md`
- 推荐架构：**MAPS（Multi-Agent with Project State）**
  - Orchestrator 项目教练调度
  - Specialist Agent 独立调用、独立工具、共享项目状态
  - 支持 Single / Pipeline / Debate / Human-in-the-loop 四种模式
- 已实现 Agent：
  - **项目教练（Orchestrator）**：解析目标并制定 Agent 执行计划
  - **学术研究员（Academic Researcher）**：调用 OpenAlex/arXiv 搜索并生成文献综述
  - **知识图谱员（Knowledge Mapper）**：把文本转化为图谱节点与关系，可一键导入
- 控制台：`BottomConsole` 的 Agent Tab 现在使用 `AgentConsole`，可手动选择 Agent 运行。
- 旧 `AgentClusterPanel` 已从主界面移除，避免与控制台职责重叠。

### 7.3 仍存在的未解决问题

1. `ChangeLogPanel` 仍以浮动面板存在，建议移入左栏或控制台。
2. 底部控制台「时序编辑器」和「逻辑树输入」Tab 仍为占位骨架。
3. `AcademicToolsPanel` 的"学术审查" Tab 尚未接入真实 AI 审查逻辑。
4. 当前 Agent 仅支持手动 Single 模式，Orchestrator 的自动调度尚未实现。
