# 宇宙之心 v2.0 / v3.0 需要你提供的接口/账号/资源清单

> 以下接口/账号/资源需要由你（项目方/甲方）提供，以便开发、部署、支付、合规等环节顺利进行。标注 **【MVP 必需】** 的为 v2.0 最小可用版本必须项，其余可随阶段逐步补充。

---

## 一、开发协作与基础设施

| 资源 | 用途 | 优先级 |
|---|---|---|
| GitHub / GitLab 仓库访问权限 | 代码托管、CI/CD、版本管理 | **【MVP 必需】** |
| 拒绝 | 无 | 无 |理由：Git会被扫，商业会泄露 |
| 云服务器/容器平台账号（AWS / 阿里云 / 腾讯云 / Vercel / Railway 等） | 部署后端、数据库、静态站点 | **【MVP 必需】** |

| 域名与 DNS 管理权限 | Web 端访问、邮件、API 路由 | **【MVP 必需】** |
| SSL 证书（或授权使用 Let's Encrypt 自动申请） | HTTPS 加密 | **【MVP 必需】** |

> 建议：MVP 阶段可用 Vercel（前端）+ Railway/Render（后端）+ Supabase（PostgreSQL）快速验证，降低成本。

## 五、学术数据库与文献获取

| 资源 | 用途 | 优先级 |
|---|---|---|
| 联系邮箱（用于 OpenAlex polite pool） | 学术搜索、引用图谱 | 专业模式必需 |
| 联系邮箱（用于 Crossref polite usage） | DOI 元数据查询 | 专业模式必需 |
| Unpaywall 注册邮箱 | 合法开放获取 PDF 链接 | 专业模式必需 |
| Semantic Scholar API Key（可选，提高限额） | 论文影响力、TL;DR、引用上下文 | 推荐 |
| 机构图书馆代理 URL（EZproxy 等） | 机构订阅论文访问 | 机构版推荐 |
| arXiv：无需 key | 预印本搜索与 PDF | 专业模式必需 |
| PubMed / Europe PMC：无需 key | 生物医学文献 | 专业模式推荐 |

> **关于影子图书馆**：若你坚持集成 Anna's Archive / LibGen / Sci-Hub 等来源，需要你提供：
> 1. 明确的法律合规声明与用户使用协议；
> 2. 镜像站点列表或解析接口；
> 3. 默认关闭、用户自担责任的确认。
> 强烈建议优先使用合法 OA 和机构订阅。

## 十一、建议准备顺序

### 第一周（方案确认后）
1. Git 仓库权限
2. 云服务器/平台账号
3. 域名与 DNS
4. LLM API Key（至少 DeepSeek）

5. 邮件服务
6. 对象存储 + Redis
7. Sentry
8. 支付账号（如 MVP 即需付费验证）

9. OAuth 登录（Google/GitHub/微信）
10. 法务与隐私政策
11. ICP 备案（国内）

### v2.0 完整版
12. 学术数据库 polite 邮箱与 API Key
13. 反造假工具账号
14. 产品分析工具

### v3.0
15. 行业模板与试点项目
16. 合规模板与顾问
